# Changelog

All notable changes to the vitruvian-orchestrator Antigravity plugin are recorded here.

## 0.2.0

First release published to its own repository. It includes the generic team that works
in any repository, the optional `.agents/team.json` team file, `team_setup` (`init` and
`sync`), the native engine (Gemini delegation is opt-in), the shared board and the live
panel.
