# Vitruvian Courier

Formerly **Courier**. Releases up to 0.3.17 are tagged `courier-v*`; later ones are `vitruvian-courier-v*`.

## Overview
Subsystem blueprint grouping child modules under `apps/desktop/vitruvian-courier`.

## Subdirectories & Boundaries
- [app](./app/README.md): Contract for apps/desktop/vitruvian-courier/app
- [engine](./engine/README.md): Component package providing implementation for apps/desktop/vitruvian-courier/engine.
- [gchat](./gchat/README.md): Component package providing implementation for apps/desktop/vitruvian-courier/gchat.
- [libsignal](./libsignal/README.md): Contract for apps/desktop/vitruvian-courier/libsignal
