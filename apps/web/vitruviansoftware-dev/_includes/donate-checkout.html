{%- comment -%} Shared checkout attribution and analytics script for /donate/ and /donate//. Resolves click source (?src=, ?source=, ?utm_source=, or sanitized document.referrer), appends ?client_reference_id= to #donate-checkout-btn, and sets data-umami-event-source= so both Stripe Checkout Sessions and Umami click events record where the donor came from. Fires a "donate-view" Umami event on load and never auto-redirects; without JavaScript, the button keeps its plain Stripe Payment Link href. {%- endcomment -%}
