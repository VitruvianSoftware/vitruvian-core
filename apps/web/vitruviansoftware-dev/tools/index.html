Trust

A tool is trusted like an app.

A tool can do anything Vitruvian can. The app starts it as an ordinary program that runs as you, with every permission Vitruvian has: if Vitruvian may read the screen or control other apps, so may the tool, with no prompt of its own. The app does not limit or check what a tool does.

So you agree once, when you add a tool from its folder in Settings, on a sheet that says exactly this, and nothing asks again. Add a tool whose source you can read or whose author you trust, as you would an app. There is no list of tools to install yet: a tool comes as a folder.

Get started

Three ways in.

The vitruvian-tool command starts a new tool, checks a folder the way the app will, and plays the app's side in a terminal.

Homebrew

Builds the command from source on your Mac, so macOS runs it without asking.

Homebrew Formula brew install VitruvianSoftware/tap/vitruvian-tool

Download

One program for Apple silicon and Intel, with its checksum. It is signed ad hoc, not with an Apple Developer ID, so clear macOS's download mark once, as the guide shows.
