# Verifying Policy

- When verifying bugs or fixes, do NOT open a new dashboard tab if one already exists.
- Refresh the existing dashboard tab before starting to verify bugs or fixes.
- If you confirmed a bug or fix, make sure to reproduce it at least twice and pay extra attention on
  the 2nd attempt to reproduce the outcome properly.
- If you need to verify again after a code change, just fresh the dashboard tab already loaded in
  the browser and NEVER open a new dashboard tab if one already exists.
