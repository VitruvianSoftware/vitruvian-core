# Packages

## Finding and adding packages

- **Find a package:** Search Backstage through its MCP server if you have it (filter the catalog to `type: library`). Otherwise, use the generated table below — both come from the same `catalog-info.yaml` files.
- **Reuse order:** Follow [AGENTS.md — Reuse before writing](../AGENTS.md#reuse-before-writing) before adding a third-party dependency or writing new code.
- **Add a package:** Use `//tools/initializer` if it has a package template. Otherwise, follow [Decision 3 of the shared-packages design](../docs/superpowers/specs/2026-11-20-shared-packages-convention.md#decision-3-what-every-package-must-have) (`README.md`, `catalog-info.yaml` with `spec.type: library`, and a public Bazel target), then refresh the table below with `bazel run //tools/packages-index -- --write`.
