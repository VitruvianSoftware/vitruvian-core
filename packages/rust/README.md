# Rust Packages

Shared Rust libraries under `packages/rust/`.

- [vitruvian-mcp-auth](./vitruvian-mcp-auth/README.md): OAuth 2.1 bearer token verifier, JWKS cache, and Protected Resource Metadata builder for Zitadel-backed MCP servers.
- [vitruvian-pycompat](./vitruvian-pycompat/README.md): Standard-library-only crate reproducing Python string, JSON, argparse, and Unicode character-table semantics for ported CLI tools.
- [vitruvian-pyjson](./vitruvian-pyjson/README.md): Serde-backed JSON parser and Python-compatible value formatter preserving key insertion order and duplicate-key override rules.
