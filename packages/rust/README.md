# Rust Packages

Nothing lives here any more. The Rust crates that used to sit under `packages/rust/` now each have their own folder named for what they do:

- [mcp-auth](../mcp-auth/README.md): OAuth 2.1 bearer token verifier, JWKS cache, and Protected Resource Metadata builder for Zitadel-backed MCP servers.
- [pycompat](../pycompat/README.md): `vitruvian-pycompat` and `vitruvian-pyjson`, the Python-compatible helpers for ported CLI tools.
