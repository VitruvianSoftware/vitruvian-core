Tools for everyone, stage C: the catalogue

Vitruvian for macOS and vitruviansoftware.dev. Static pictures of the new screens, before any code.

100%

Stage C lets a person install a tool from a curated list, the catalogue, in two steps: pick it, then agree on the same sheet a folder gets. It adds one button to the card "Tools from outside", one sheet that lists the catalogue, one line on the agreement sheet, four refusals, "Update available" on a tool's row and detail, and a page of the website. Every sentence in a mock-up is the exact English text of the plan's string table. The app's English says "catalog", as the rest of its English is American; this page and the plan say "catalogue". Tool names, publishers, versions and summaries are examples.

"Browse Tools…" sits before "Add a Tool…": the catalogue is the easier way in, and a folder stays one click further. The card's empty line is unchanged.

Choice: a second button, not a menu on the first. Each button says where it leads, and neither hides the other.

Alternative: a page of its own in the Settings sidebar. It would cost a translated page title and an edit to the sidebar's fixed list, for one list.

"From" names the tool's source instead of a folder: the folder the download was unpacked into is the app's own and is deleted when the sheet closes. One plain sentence each, and nothing on disk after any of them. "Not the pinned one" covers a size or a checksum that differs. "Not the tool it says" covers a zip that is no tool, one with a path that would leave its folder or a link, and a manifest with another id or version. The technical reason goes to no screen: CI already checked the same things, so any of these means something changed after the listing.

Choice: reopening the sheet tries again; there is no Try Again button. A download that could not be fetched uses the first sentence in an alert, under the same title as the last two.

Alternative: a sentence for each check (size, checksum, zip, manifest). Four more strings in fifteen languages for a difference only a tool's author can act on.

f. The website's catalogue page

Tools

The tool catalog.

Tools VitruvianSoftware lists for the Vitruvian app. Install one from inside the app: Settings, Features, Tools from outside, Browse Tools.

What listing means

VitruvianSoftware read each tool's manifest and pinned its download to one file and its checksum; the app refuses any other file. A tool can still do anything Vitruvian can on your Mac, and the app asks before it installs one.
