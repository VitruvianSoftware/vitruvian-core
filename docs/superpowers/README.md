# Superpowers — agent specs & plans (working area)

This tree is the working area for the
[superpowers](https://github.com/obra/superpowers) agent workflow used in this repo:

- **`specs/`** — approved design documents, written before implementation.
- **`plans/`** — checkbox execution plans that an agent (or human) works through,
  typically referencing a spec.

Both are **point-in-time artifacts**, dated `YYYY-MM-DD-…`. A plan being present here
does not mean it is current guidance — check its `Status:` line; several are complete
and several are in flight. When a spec/plan is done and its outcome is reflected in
the living docs, move it to [`docs/archive/`](../archive/README.md).

Living documentation — the stuff you should trust — starts at
[`docs/README.md`](../README.md).
