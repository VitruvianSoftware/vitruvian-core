## Bazel run verbs

Generated by `pulumi_project` ([`tools/pulumi/defs.bzl`](../../tools/pulumi/defs.bzl)) for every project.

| Verb | Runs | Notes |
|---|---|---|
| `:preview` | `pulumi preview` | dry run; add `-- --diff` / `-- --refresh` |
| `:up` | `pulumi up` | apply; add `-- --yes` for non-interactive |
| `:refresh` | `pulumi refresh` | reconcile state to reality (no resource changes) |
| `:destroy` | `pulumi destroy` | tear down |
| `:config` | `pulumi config` | e.g. `:config -- set <key> <value>` |
| `:setup` | guided helper | prereqs, login, stack select, hints (idempotent) |

Everything after `--` is forwarded to `pulumi` verbatim.

## Command cheat sheet

```bash
# Bootstrap a project (prereqs, login, stack)
bazel run //infrastructure/pulumi/<project>:setup

# Standard cycle
bazel run //infrastructure/pulumi/<project>:preview -- --diff
bazel run //infrastructure/pulumi/<project>:up

# Stale, long-lived stack: refresh first
bazel run //infrastructure/pulumi/<project>:preview -- --refresh --diff
bazel run //infrastructure/pulumi/<project>:refresh -- --yes

# Set config (secret values use --secret via pulumi)
bazel run //infrastructure/pulumi/<project>:config -- set <key> <value>
bazel run //infrastructure/pulumi/<project>:config -- set --secret <key> <value>

# One-time, org-level GitHub App for repo_config CI
bazel run //tools/pulumi:create-app

# Ad-hoc GCP work under the pinned identity
export GOOGLE_OAUTH_ACCESS_TOKEN="$(gcloud auth print-access-token --account=<account>)"
```

## GCP identity map

File: [`infrastructure/gcp-identities.tsv`](../../infrastructure/gcp-identities.tsv).
Whitespace-separated; `#` comments and blank lines skipped; `-` in column 1 = a
reference-only row (not resolved).

| Column | Meaning |
|---|---|
| `infra_dir` | workspace-relative Pulumi project dir (resolver key); `-` = reference-only |
| `account` | Google account email to authenticate as |
| `gcp_project` | default project → `GOOGLE_CLOUD_PROJECT` / `CLOUDSDK_CORE_PROJECT`; `-` if N/A |
| `purpose` | free text (last column) |

Resolver: [`tools/pulumi/resolve_identity.sh`](../../tools/pulumi/resolve_identity.sh)
· test: `bazel test //tools/pulumi:resolve_identity_test`.

## Environment variables

| Variable | Set by | Used by |
|---|---|---|
| `GOWORK=off` | the wrapper (always) | Pulumi's internal `go build` for the standalone module |
| `GOOGLE_OAUTH_ACCESS_TOKEN` | the wrapper (mapped GCP projects) | GCP + Cloudflare providers |
| `GOOGLE_CLOUD_PROJECT`, `CLOUDSDK_CORE_PROJECT` | the wrapper (when map has a project) | GCP provider default project |
| `GITHUB_TOKEN` | you / CI | GitHub provider (sync-auth, repo_config) |
| `PULUMI_ACCESS_TOKEN` | CI secret | Pulumi Cloud backend in Actions |
| `BUILDBUDDY_API_KEY` | CI secret / `user.bazelrc` | RBE (`--config=remote`) — see [remote-build](../guides/remote-build.md) |

## File & secret locations

| What | Where | In git? |
|---|---|---|
| Project program | `infrastructure/pulumi/<project>/main.go` (+ `pkg/`, `modules/`) | yes |
| Pulumi project def | `infrastructure/pulumi/<project>/Pulumi.yaml` | yes |
| Stack config (templates) | `Pulumi.*.example.yaml` / `Pulumi.dev.yaml.example` | yes |
| Stack config (real, local) | `Pulumi.local.yaml`, `.env` | **no — git-ignored** |
| Encrypted secrets | `secure:` blobs in committed `Pulumi.<stack>.yaml` (cloud-backed) | yes (encrypted) |
| Identity map | `infrastructure/gcp-identities.tsv` | yes |
| Wrappers | `tools/pulumi/pulumi_cmd.sh`, `pulumi_setup.sh`, `defs.bzl` | yes |

## Related CI workflows

Under [`.github/workflows/`](../../.github/workflows).

| Workflow | Trigger | Purpose |
|---|---|---|
| `ci.yaml` | push/PR to `main` | `build-test` (RBE), `build-macos`, `license-check` |
| `_repo-config-preview.yaml` | PR touching `repo_config/**` (gated `REPO_CONFIG_PREVIEW_ENABLED`) | post `pulumi preview --diff` comment |
| `_repo-config-apply.yaml` | push to default branch, same path (gated `REPO_CONFIG_AUTO_APPLY`) | `pulumi up` |
| `_copybara-export.yaml` + per-component callers, `copybara-import-pr.yaml` | push / `repository_dispatch` | [Copybara sync](../admin/copybara-sync.md) (uses sync-auth creds) |
| `dependabot-*.yml` | Dependabot / schedule | bazel reconcile + auto-merge (uses sync App) |
